# Week 3 Agent Exercise — Evaluations

This folder contains evaluation cases and metrics for the 3rd week agent app (`app/week3-agent`).

- `adversarial_cases.json` — adversarial inputs
- `chat_cases.json` — conversational evaluation scenes
- `classification_cases.json` — classification checks
- `extraction_cases.json` — extraction scenarios
- `expected_metrics.json` — target scores
- `run_eval.py` — evaluation runner
- `results/` — output from runs
